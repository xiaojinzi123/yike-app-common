1. compose-miuix-ui
   项目：https://github.com/miuix-kotlin-multiplatform/miuix
   许可：Apache License 2.0
   范围：部分控件、偏好设置项、滚动回弹 / overscroll、弹簧动画与搜索栏等，
        已按 NexioUI 的包结构与 API 重写。派生文件在文件头注明了来源。

   许可：Apache License 2.0

=======================================================================

包括 `interaction/SpotlightShader.kt` 中的 AGSL 光照实现与 `ripple` / `motion`
中的动效曲线。相关名称、界面与实现的权利归小米集团所有；本项目不包含其
资源文件，仅作观感兼容。
